# APNG-phantom-tank (APNG伪装工具)

移动端 (Android) 用于制作与发送在 QQ 或支持 APNG 格式解码软件的幻影坦克伪装图片工具。
基于 **APNG (Animated Portable Network Graphics) 特殊隐写机制** 实现，完全本地离线处理，无需网络上载，保护隐私安全。

---

## 📌 核心原理

本工具利用 APNG 规范向下兼容标准 PNG 的协议特性：
1. **默认静止帧 (`IDAT`)**：写入伪装封面（内置经典蓝底封面或自定义图片）；
2. **隐藏动画帧 (`fcTL` + `fdAT`)**：写入真实图片（静态图或 GIF 动图）；
3. **保活帧**：添加 1x1 像素透明保活帧（`blend_op = 1` 覆盖混合），使真实内容播放后持久保留；
4. **隐写标识 (`tEXt`)**：注入隐写标记，便于工具无损剥离还原。

由于聊天软件（如 QQ、微信）在聊天气泡和缩略图列表中默认使用**静态快速渲染管线**，对方第一眼只能看到封面图；对方点开大图或使用本工具点击**「还原真图」**，即可 100% 无损提取原始画质内容。

## 📱 安卓版特性 (Android APK v1.3.1 重大更新)

- **图片伪装 (支持单张与批量多选)**：
  - 支持单张或一次性批量选择多张图片（JPG、PNG、WEBP 静态图与 GIF 动图）；
  - 批量伪装时，封面图左上角自动绘制序号徽章（如 1, 2, 3...）；
  - 内置经典蓝色伪装封面，支持自选相册图片作为封面，可随时一键恢复默认；
  - 伪装成功后提供**双重视角实时预览**（左：对方视角封面，右：点开/还原的真实内容）；
  - 支持一键**全部保存至系统相册**（`Pictures/PNG伪装` 目录）或调起系统**批量发送分享**直接发送给好友。
- **还原真图 (支持批量多选提取)**：
  - 自动检测并识别收到的伪装 APNG 文件，支持一次性批量选择多个伪装文件；
  - 一键批量提取并还原隐藏的真实图片 / 真实动图；
  - 提供大图预览、一键全部保存相册与批量对外分享。
- **动图智能还原为标准 GIF (v1.3.1 新增)**：
  - 智能检测隐藏帧特征，当识别为动态隐写或隐藏帧数 ≥ 5 时，自动将隐藏动画重组并编码还原为标准的 `.gif` 动图格式；
  - 彻底解决聊天软件中伪装动图提取后变为静态单张的问题，相册保存、分享与历史记录全面支持 GIF 动态解析。
- **自定义补齐底色 (黑/白/红/绿/蓝/黄) (v1.3.1 新增)**：
  - 当真实图片尺寸大于封面或宽高比不一致时，四周默认补齐底色由原先的蓝色优化为百搭的**纯黑色**；
  - 在主页伪装设置中新增可视化 6 色选择器，可自由选择黑、白、红、绿、蓝、黄作为四周自适应填充底色。
- **历史记录与本地缓存管理 (v1.3 新增)**：
  - 顶部导航栏新设「历史记录」专属栏目，展示曾经生成的所有伪装图与还原提取的原图；
  - 顶部实时统计当前历史缓存数量及所占存储空间；
  - 记录列表支持异步高清缩略图、点击查看大图、单项一键存入系统相册、单独分享与单条删除；
  - 提供一键「清空所有缓存」功能，快速释放手机本地存储空间。
- **自定义封面保存配置 (v1.3 新增)**：
  - 封面区域提供「保存当前封面」按钮；
  - 更换封面后点击保存，该封面将持久化生效，下次打开或重启软件仍使用该封面；
  - 更换封面后若不点保存，则仅本次运行有效（单次更换行为）；
  - 随时点击「恢复默认」，即一键恢复并持久保存为内置官方经典封面。
- **纯净与安全**：
  - 100% 纯本地离线处理，不包含任何网络请求；
  - 无需多余敏感权限，支持 Android 7.0 至 Android 14+；
  - 体积仅约 380 KB，纯原生轻量无冗余库。

## ⚠️ 发送注意事项 (极为重要)

- **QQ / 微信发送图片会默认被服务器有损压缩转码**，转码会剔除动画扩展帧（`fcTL`、`fdAT`），导致隐藏的真实内容丢失！
- **正确发送方式**：
  1. 手机 QQ 发送图片时，**务必勾选【原图】**；
  2. 或通过发送【文件】（以 `.png` 文件格式）发送给对方；
  3. 对方保存文件后，在手机上打开本工具点击「还原真图」，即可无损提取出真实原图。
