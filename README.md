# APNG-phantom-tank (APNG伪装工具)

移动端 (Android) 用于制作与发送在 QQ 或支持 APNG 格式解码软件的幻影坦克伪装图片工具。
基于 **APNG (Animated Portable Network Graphics) 特殊隐写机制** 实现，完全本地离线处理，无需网络上载，保护隐私安全。  
**项目已转向更新网页端：https://png-phantom-tank.pages.dev/**  
**此后会优先更新在Web端，app端随缘更**

---

## 📌 伪装图核心原理

本工具利用 APNG 规范向下兼容标准 PNG 的协议特性：
1. **默认静止帧 (`IDAT`)**：写入伪装封面（内置经典蓝底封面或自定义图片）；
2. **隐藏动画帧 (`fcTL` + `fdAT`)**：写入真实图片（静态图或 GIF 动图）；
3. **保活帧**：添加 1x1 像素透明保活帧（`blend_op = 1` 覆盖混合），使真实内容播放后持久保留；
4. **隐写标识 (`tEXt`)**：注入隐写标记，便于工具无损剥离还原。

由于聊天软件（如 QQ、微信）在聊天气泡和缩略图列表中默认使用**静态快速渲染管线**，对方第一眼只能看到封面图；对方点开大图或使用本工具点击**「还原真图」**，即可 100% 无损提取原始画质内容。

## 🌐 其他功能

- **图片伪装 (支持单张与批量多选)**：
  - 支持单张或一次性批量选择多张图片（JPG、PNG、WEBP 静态图与 GIF 动图）；
  - 批量伪装时，封面图左上角自动绘制序号徽章（如 1, 2, 3...）；
  - 内置经典蓝色伪装封面，支持自选图片作为封面，可随时一键恢复默认；
  - 6 色补齐底色（黑/白/红/绿/蓝/黄）自适应留白，封面与底色自动保存在浏览器本地；
  - 伪装成功后提供**双重视角实时预览**（左：对方视角封面，右：点开/还原的真实内容）；
  - 「封面设置」浮层：防吞（测试功能，让每次生成的封面哈希略有不同，降低被判重吞图的概率）与保留原图元数据（EXIF / 位置 / AI 提示词参数，默认去除）。
- **还原真图 (支持批量多选提取)**：
  - 自动检测并识别伪装 APNG 文件，一键批量提取隐藏的真实图片 / 真实动图；
  - 动态隐写 / 多帧动画智能还原为标准 GIF 动图；
  - 附带展示该伪装图的封面，可单独保存；
  - 批量还原后点开大图可左右切换浏览全部结果。
- **拆解动图**：把 GIF 逐帧拆解为 PNG，一键保存全部帧；
- **图片混淆**：基于 Gilbert 空间填充曲线的可逆像素置换，混淆 / 解混淆无损还原；支持多图模式批量处理；
- **清除信息**：批量抹除图片中的 EXIF / 位置 / AI 提示词等隐藏信息，输出不含元数据的 PNG；
- **电子包浆**：复刻 Electrical Weathering 做旧效果，官窑 / 民窑双模式，噪点 / 泛绿 / 压缩 / 缩放可调，轻 / 中 / 重预设，可叠加知乎 / 微博 / 贴吧 / 头条水印；
- **图片处理 (五个子功能)**：
  - 图片拼接：多图拖拽排序、圆角、实时预览；
  - 网格拼接：等分 2~16 份 + 点击边线自由合并拼版（支持 L 形），横切 / 竖切、撤回；
  - 九宫格切图：可选先裁方正方形；
  - 覆盖图片：图层拖拽 / 缩放 / 旋转、文字、精确尺寸；
  - 相片处理：标准 1 寸 / 2 寸证件照制作（白 / 蓝 / 红底色）与 5 寸相纸排版；
- **图片工具 (三个子功能)**：
  - MD5 哈希：批量读取文件 MD5 / SHA 系列，追加字节批量修改 MD5 防判重（每个文件独立随机字节）；
  - 图片压缩：压缩方式可选仅画质 / 仅尺寸 / 画质+尺寸，画质滑条实时预览，逐张体积对比；
  - 格式转换：PNG / JPG / WEBP 互转，透明底填充处理；
- **信息处理**：
  - 信息查看：解析并展示 EXIF 拍摄参数、GPS 位置（附地图链接）、文本块（含 AI 提示词参数，可导出 txt）；
  - 信息清除：批量抹除隐藏信息后输出纯净文件；
- **历史记录**：基于 IndexedDB 的离线历史管理，支持大图预览（缩放 / 拖动 / 批量切换浏览）；
- **界面与体验**：
  - 功能页支持路径直达（/split /chaos /clean /weathering /processing /md5）；
  - 支持日间 / 夜间模式，默认跟随系统，可手动切换并记住选择；
  - 所有功能支持点击与拖拽两种方式导入图片，100% 纯前端本地处理，图片绝不上传服务器。
 
## 安全

  - 100% 纯本地离线处理，不包含任何网络请求；
  - 无需多余敏感权限，支持 Android 7.0 至 Android 14+；

## ⚠️ 发送注意事项 (极为重要)

- **QQ / 微信发送图片会默认被服务器有损压缩转码**，转码会剔除动画扩展帧（`fcTL`、`fdAT`），导致隐藏的真实内容丢失！
- **正确发送方式**：
  1. 手机 QQ 发送图片时，**务必勾选【原图】**；
  2. 或通过发送【文件】（以 `.png` 文件格式）发送给对方；
  3. 对方保存文件后，在手机上打开本工具点击「还原真图」，即可无损提取出真实原图。
