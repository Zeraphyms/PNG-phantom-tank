# APNG 图片伪装工具 - 纯前端免登录 Web 版

基于 HTML5 Canvas、纯前端 APNG 与 GIF 编解码规范实现的移动端幻影坦克伪装工具网页版。

## 🌟 特性
1. **纯前端本地处理**：100% 运行在访客浏览器内，图片绝不上载任何外部服务器，保护隐私安全。
2. **免登录即开即用**：部署在 Cloudflare Pages，不限制流量，任何用户通过微信、QQ、浏览器点开直接使用。
3. **功能对齐移动端 v1.4.1（Web v1.5.8）**：
   - 支持单张 / 批量图片伪装，自动居中留白与序号徽章；
   - 自定义封面与 6 色补齐底色（黑/白/红/绿/蓝/黄）自适应留白；
   - 封面与底色自动持久化保存在浏览器本地（刷新重启不丢失）；
   - 伪装封面提供「封面设置」浮层：防吞（测试功能，默认开启，让每次封面略有不同以降低被判重吞图的概率）与保留原图元数据（EXIF / 位置 / NovelAI 提示词参数，默认去除）；
   - 支持提取还原真图，动态隐写 / 多帧动画智能还原为标准 `.gif` 动图；
   - 基于 IndexedDB 的离线历史记录管理，支持一键清空与勾选删除指定条目；
   - 拆解动图：把 GIF 逐帧拆解为 PNG，可一键保存全部帧；
   - 图片混沌：基于 Gilbert 空间填充曲线的可逆像素置换，混淆 / 解混淆无损还原，超 2000 万像素或单边超 6000 自动等比缩小，可选择「不缩小」按原图处理；支持一键切换多图模式，批量混淆 / 解混淆并一键保存全部结果；
   - 四个功能均支持点击与拖拽两种方式导入图片；
   - 还原真图后附带展示该伪装图的封面，可单独保存；
   - 大图查看支持滚轮 / 双指缩放与拖动查看局部（历史记录同步支持）；
   - 批量还原后点开大图可左右切换（方向键 / 触摸滑动）浏览全部还原结果，拆解帧同样支持；
   - 混淆 / 解混淆结果可点开大图查看，支持缩放与拖动。
   - 清除信息：批量抹除图片中的 EXIF / 位置 / NovelAI 提示词等隐藏信息，输出不含元数据的 PNG，按原始尺寸处理不缩小；
   - 电子包浆：复刻 Electrical Weathering 的做旧效果，官窑（YUV 误差累积，慢而自然）/ 民窑（矩阵混合，快）双模式，噪点 / 泛绿 / 压缩 / 缩放四参数可调，轻 / 中 / 重预设，可叠加知乎 / 微博 / 贴吧 / 头条水印；
   - 图片处理（五个子功能）：图片拼接（拖拽排序/圆角/实时预览）、网格拼接（等分 2~16 份 + 点击边线自由合并拼版，支持横切/竖切与撤回）、九宫格切图、覆盖图片（图层拖拽/缩放/旋转、文字、精确尺寸）、相片处理（标准 1 寸/2 寸证件照制作与 5 寸相纸排版）；
   - MD5 工具：批量读取文件 MD5/SHA1/SHA256/SHA384/SHA512，追加字节批量修改 MD5 防判重（每个文件独立随机字节），副本自动对账新哈希；
   - 图片压缩：多图统一 JPG，画质滑条实时预览大图（逐张体积对比、单删/全删），保存为原图高清压缩；
   - 格式转换：PNG/JPG/WEBP 互转（透明底填充处理），已选列表与结果列表均可单删/全删；
   - 信息查看：解析并展示图片中的 EXIF 拍摄参数、GPS 位置（附地图链接）、文本块，敏感信息标红提示；
   - 更多功能各页面支持路径直达（/split /chaos /clean /weathering /processing），选中子功能时底部显示功能名与「回到主页」。
4. **界面与主题**：
   - 渐变顶栏 + 功能概览条，卡片式分区与步骤标识；
   - 支持日间 / 夜间模式，默认跟随系统，可手动切换并记住选择。
