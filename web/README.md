# APNG 图片伪装工具 - 纯前端免登录 Web 版

基于 HTML5 Canvas、纯前端 APNG 与 GIF 编解码规范实现的移动端幻影坦克伪装工具网页版。

## 🌟 特性
1. **纯前端本地处理**：100% 运行在访客浏览器内，图片绝不上载任何外部服务器，保护隐私安全。
2. **免登录即开即用**：部署在 Cloudflare Pages，不限制流量，任何用户通过微信、QQ、浏览器点开直接使用。
3. **功能对齐移动端 v1.4.1（Web v1.4.4）**：
   - 支持单张 / 批量图片伪装，自动居中留白与序号徽章；
   - 自定义封面与 6 色补齐底色（黑/白/红/绿/蓝/黄）自适应留白；
   - 封面与底色自动持久化保存在浏览器本地（刷新重启不丢失）；
   - 支持提取还原真图，动态隐写 / 多帧动画智能还原为标准 `.gif` 动图；
   - 基于 IndexedDB 的离线历史记录管理与一键清空缓存；
   - 拆解动图：把 GIF 逐帧拆解为 PNG，可一键保存全部帧；
   - 图片混沌：基于 Gilbert 空间填充曲线的可逆像素置换，混淆 / 解混淆无损还原；
   - 四个功能均支持点击与拖拽两种方式导入图片。
4. **界面与主题**：
   - 渐变顶栏 + 功能概览条，卡片式分区与步骤标识；
   - 支持日间 / 夜间模式，默认跟随系统，可手动切换并记住选择。
