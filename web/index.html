工作原理
本工具采用 APNG (Animated Portable Network Graphics) 特殊隐写机制：
• 默认静止帧 (IDAT)：写入伪装封面图片。
• 隐藏动画帧 (fcTL+fdAT)：写入你的真实原图或动态 GIF。
• 聊天软件在相册缩略列表中只能看到封面；对方点开或使用本工具点击「还原真图」即可查看和提取完整真实内容。
发送到 QQ / 微信重要提醒
• QQ/微信以默认「普通图片」方式发送会进行二次有损转码，剔除动画扩展帧导致隐藏内容丢失！
• 正确发送方式：
1. 手机 QQ 发图时务必勾选【原图】；或点击加号以【文件】形式发送 .png 文件。
2. 对方保存文件后打开本网页点击「还原真图」，即可无损提取出原图 / 动图！

防吞（测试功能）实现原理

聊天软件（如 QQ / 微信）在发送图片时，会对图片做去重判断：如果它认为两张图的“内容指纹”相同，就只保留其中一张，表现为“吞图”。

本功能不改动你还原后看到的真实图片，只在伪装封面上做两层极轻微的随机扰动：

  • 逐像素随机扰动：封面上每个像素的 R / G / B 通道各自随机 ±2 级（数值到达 0 或 255 时钳制，不会翻转成异色）。因为每个像素独立随机，每次生成的封面组合都不同。
  • 整体随机色偏：整张封面每个通道再随机偏移 −1 ~ +1，让整体色调有极轻微变化，比纯噪声更抗二次压缩。

这样一来，每次生成的封面在缩略图 / 哈希指纹层面都不相同，从而降低被判重、被“吞”的概率；而肉眼几乎看不出差别。

说明：平台判重算法并不公开，且会随版本变化，因此本功能属于测试性质，不能保证对所有平台 100% 有效。若发现无效，欢迎前往 GitHub 仓库反馈。
